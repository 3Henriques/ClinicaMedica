## Como rodar o projeto

### 1. Clonar ou baixar o projeto

Baixe o projeto ou clone o repositório. Depois, acesse a pasta do projeto pelo terminal:

```bash
cd ClinicaMedica
```

### 2. Configurar o Firebase

O projeto usa Firebase e espera encontrar o arquivo `.env.local.js` na raiz do projeto.

Por motivos de segurança, esse arquivo não fica versionado no repositório. Cole o código que está em um arquivo .txt enviado via Teams.

### 3. Instalar as dependências

Na raiz do projeto, execute:

```bash
npm install
```

### 4. Rodar a aplicação

```bash
npm run start
```
